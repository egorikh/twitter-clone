# Twitter Clone (сервис микроблогов)

Этот проект — учебный бэкенд-сервис микроблогов.  
Он реализует ключевой функционал корпоративной соцсети, аналогичной Twitter, и демонстрирует навыки проектирования и разработки серверной части приложений.

---

## 🚀 Основные возможности
- Создание твитов (с текстом и изображениями)
- Удаление собственных твитов
- Подписка и отписка от пользователей
- Лайки и снятие лайков
- Получение ленты твитов от пользователей, на которых оформлена подписка (сортировка по популярности)
- Получение профиля текущего пользователя и других пользователей
- Документация API через Swagger

---

## 🛠️ Технологический стек
- **Python 3.10+**
- **FastAPI** — фреймворк для построения REST API
- **PostgreSQL** — база данных для хранения твитов, пользователей, подписок, лайков и медиа
- **SQLAlchemy** — ORM для работы с БД
- **Docker & Docker Compose** — контейнеризация и удобный запуск
- **Swagger UI** — автогенерация документации

---

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/egorikh/twitter-clone.git
cd twitter-clone
```

### 2. Запуск через Docker
```bash docker-compose up --build ```

После успешного запуска:

- **API** доступно по адресу: [http://localhost:8000/api](http://localhost:8000/api)  
- **Swagger-документация**: [http://localhost:8000/docs](http://localhost:8000/docs)  

---

## 🔑 Авторизация
- Для всех запросов требуется передавать заголовок `api-key`.  
- Можно использовать **любой ключ**, если в базе есть пользователь с таким значением.

Пример: 
```http
GET /api/tweets
Headers:
  api-key: user123
```

---

## 📖 Основные эндпоинты

| Метод      | Путь                     | Описание                      |
| ---------- | ------------------------ | ----------------------------- |
| **POST**   | `/api/tweets`            | Создать новый твит            |
| **DELETE** | `/api/tweets/{id}`       | Удалить твит                  |
| **POST**   | `/api/medias`            | Загрузить изображение         |
| **POST**   | `/api/tweets/{id}/likes` | Поставить лайк                |
| **DELETE** | `/api/tweets/{id}/likes` | Убрать лайк                   |
| **POST**   | `/api/users/{id}/follow` | Подписаться на пользователя   |
| **DELETE** | `/api/users/{id}/follow` | Отписаться от пользователя    |
| **GET**    | `/api/tweets`            | Получить ленту твитов         |
| **GET**    | `/api/users/me`          | Профиль текущего пользователя |
| **GET**    | `/api/users/{id}`        | Профиль пользователя по ID    |
